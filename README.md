# MeetMind AI

AI-powered meeting notes SaaS built with Next.js, Prisma and Gemini.

## Features
- Google OAuth login
- Upload meeting transcript
- AI summary generation
- AI action item extraction
- Dashboard to manage meetings
- Delete meetings

## Tech Stack
Next.js 14  
NextAuth  
Prisma + PostgreSQL  
Google Gemini API  
Tailwind CSS

## Run locally
npm install
npx prisma db push
npm run dev
